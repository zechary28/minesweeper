# Minesweeper

A minesweeper simulation with an autosolver, built with C++ and raylib.

## Dependencies

- [raylib](https://github.com/raysan5/raylib) — follow the [installation guide](https://github.com/raysan5/raylib/wiki/Working-on-GNU-Linux) for your platform

## Build & Run

```bash
git clone https://github.com/zechary28/minesweeper.git
cd minesweeper
make
./game
```

## Controls

| Key | Action |
|-----|--------|
| `F` | Toggle fullscreen |
| `Win + Shift + ←/→` | Move window between monitors |
